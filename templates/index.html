🎯 Lab Objective

Master every HTTP method — GET, POST, PUT, DELETE, PATCH, HEAD, OPTIONS, and TRACE — and learn how flawed authorization logic creates bypasses on each of them.

Three flags are hidden across three targets. Retrieve all three.

Target 1 — /admin/reset

The developer protected this endpoint by checking if request.method == "GET" and returning 401. Every other method slides right past.

Target 2 — /file

Filter scans request.form only (POST body). Query strings, PUT bodies, PATCH bodies, and DELETE calls are all unfiltered.

Target 3 — /trace

TRACE-enabled servers echo the entire request — including Authorization headers, cookies, and proxy routing. This is Cross-Site Tracing (XST) territory. 

curl -X TRACE http://127.0.0.1:5000/trace -H "Authorization: Bearer secret"

Response body echoes your header back — the flag is in the body and in X-Trace-Flag.

🔍 Recon: Always Start With OPTIONS

Before attacking, enumerate allowed methods on every endpoint:

curl -i -X OPTIONS http://127.0.0.1:5000/admin/reset
curl -i -X OPTIONS http://127.0.0.1:5000/file
curl -i -X OPTIONS http://127.0.0.1:5000/trace

Each returns an Allow header listing every reachable method.
